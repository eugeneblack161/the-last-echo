# The Last Echo

Мрачная история о памяти, связи и цене выбора. Проект создан на Next.js, React и TypeScript. Прогресс хранится в браузере в трёх слотах.

## Запуск

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Проверки

```bash
npm run lint
npm run build
```
